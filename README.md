# Mondo Bongo — Premium Website Demo

Premium food-first concept for Mondo Bongo in Francavilla al Mare.

## Creative direction

The site deliberately shifts the visual hierarchy away from nightlife/pub cues and toward a refined contemporary Abruzzese restaurant identity, with emphasis on:

- pizza and the 48/72h dough process
- arrosticini, including handmade 40 g options
- Abruzzese salumi, cheeses and regional flavours
- braceria
- Abruzzese wine and craft beer
- a menu-first user experience

Events, karaoke, live music and family entertainment are kept as secondary parts of the experience rather than the lead message.

## Menu content

Menu names, ingredients and prices used in the demo were taken from the Mondo Bongo menu available through Deliveroo during September 2026. The live restaurant menu should always be treated as the final source for pricing and availability.

## Images

The current photographs are free Unsplash atmosphere images used only for this website concept. They should be replaced with approved official Mondo Bongo photography before using the site as a final production website.

## Stack

Static HTML, CSS and vanilla JavaScript. No build command is required, so the project can be deployed directly through Netlify or GitHub Pages.
